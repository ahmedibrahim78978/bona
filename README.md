## Features
- Personal bio and hobbies list (ESP32 electronics, Assetto Corsa, Football)
- HTML5 skill progress bars
- Embedded audio and video players
- Weekly schedule table
- Collapsible secret fact section (`<details>`)
- Visitor message form
